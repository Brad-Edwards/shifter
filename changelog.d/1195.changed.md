The experiments feature (`cms/experiments`) is now gated off by default behind a new `EXPERIMENTS_ENABLED` flag and is hidden from the navigation. The feature was never finished — its command executor does not exist, so a run cannot complete on any cloud — and it was also AWS-only. Flagging it off keeps the half-built path from launching a non-existent executor or blocking GCP deployment; whether to build, redesign, or remove it is tracked in #1195.

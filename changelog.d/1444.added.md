Added the ACES-native provisioning core (ADR-031, behind the `SHIFTER_ACES_NATIVE_PROVISIONING` feature flag, default off): a locked, cyberscript-free `ProvisioningSpec` contract (`shared.aces.provisioning_spec`) that losslessly represents a compiled ACES provisioning topology (nodes with os family, count, cpu/memory, image reference, services, network membership; networks with cidr, gateway, isolation, node ACLs), and a Shifter ACES RuntimeTarget backend (`shared.aces.runtime_target`) that faithfully interprets a compiled ACES `ProvisioningPlan` into that spec — reading node resources/image/services/network-membership and network cidr/gateway — and dispatches it through an injected port, superseding the earlier `scenario_ref` passthrough. The backend fails closed on any out-of-envelope term and is verified by the ACES-owned conformance suite (fixture + a live target probe that rejects a vacuous pass). An import-linter contract confines the ACES SDL tooling to `shared.aces`. With the flag off there is no behaviour change; the existing cyberscript range path stays authoritative.

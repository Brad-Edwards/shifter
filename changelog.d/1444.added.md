Added the foundation for the ACES-native provisioning core (ADR-031, behind the `SHIFTER_ACES_NATIVE_PROVISIONING` feature flag, default off): a locked, cyberscript-free `ProvisioningSpec` contract (`shared.aces.provisioning_spec`) that losslessly represents a compiled ACES provisioning topology (nodes with os family, count, cpu/memory, image reference, services, network membership; networks with cidr, gateway, isolation, ACL rules), and an import-linter contract confining the ACES SDL tooling to `shared.aces`. With the flag off there is no behaviour change; the existing cyberscript range path stays authoritative.
